The Best Windows - النسخة المطورة

طريقة التحديث على GitHub من الموبايل:
1) افتح مستودع GitHub: the-best-windows.
2) اضغط على ملف index.html.
3) اضغط علامة القلم Edit this file (قد تحتاج قائمة الثلاث نقاط).
4) لا تحاول استبدال الكود يدويًا من الهاتف. الأفضل تنزيل هذا الملف index.html من ملف ZIP ثم في المستودع اختر Add file > Upload files.
5) ارفع index.html الجديد وحده إلى جذر المستودع، ووافق على Commit changes. إذا ظهرت رسالة أن الملف موجود بالفعل، اختر استبدال/Commit التعديل.
6) انتظر دقيقة أو دقيقتين وافتح رابط الموقع مع تحديث الصفحة.

الميزات:
- أنواع ثابتة قابلة لتعديل السعر وطريقة التسعير: أبواب، شبابيك، سلك بليسيه، زجاج، إكسسوارات، نقل، تركيب وبند آخر.
- إضافة أنواع جديدة لقائمة الأسعار.
- بنود متعددة لكل عرض سعر، مقاسات وكميات وأسعار منفصلة.
- خصم مبلغ أو نسبة، مقدم ومتبقي.
- طباعة/حفظ PDF من نافذة الطباعة.
- حفظ الإعدادات والأسعار والعروض محليًا على نفس المتصفح، وتصدير/استيراد نسخة احتياطية.

ملاحظة: الأسعار الابتدائية مجرد قيم قابلة للتعديل. زجاج/إكسسوارات/نقل/تركيب يبدأ سعرها بصفر حتى تدخل أسعارك الفعلية. البيانات المحلية لا تتزامن تلقائيًا بين الأجهزة أو المتصفحات.
