The Best Windows — حاسبة أسعار وعروض UPVC

تشغيل:
1. فك ضغط الملف.
2. افتح index.html في Chrome أو Edge.
3. عدّل بيانات الشركة والأسعار والمقاسات.
4. اضغط «إنشاء / تحديث عرض السعر».
5. اضغط «طباعة / حفظ PDF» ثم اختر «حفظ بتنسيق PDF».

نشر مجاني عبر GitHub Pages:
1. أنشئ حسابًا في https://github.com
2. أنشئ مستودعًا جديدًا باسم the-best-windows.
3. ارفع index.html إلى المستودع من Add file > Upload files ثم Commit changes.
4. افتح Settings > Pages.
5. اختر Deploy from a branch، ثم main والمجلد /(root)، واضغط Save.
6. انتظر ظهور رابط الموقع في صفحة Pages.

ملاحظات:
- الموقع ثابت ولا يحتاج إلى خادم مدفوع.
- إعدادات الأسعار تُحفظ محليًا في المتصفح.
- استخدم «حفظ نسخة بيانات» للاحتفاظ بنسخة احتياطية من عروضك.
- إخراج PDF يستخدم طباعة المتصفح للحفاظ على اتصال الحروف العربية.
- النسخة الأولى لا تحتوي على مزامنة سحابية بين الأجهزة.
